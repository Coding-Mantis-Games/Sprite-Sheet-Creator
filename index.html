How to create a 2D animation

  1. Create a character image with an AI tool such as ChatGPT or Gemini. Use a solid background color that does not appear on the character.
  2. Create a character animation video with a video-generation tool such as Google Flow or Grok.
  3. Upload the video to EZGIF Video to PNG to convert it into an image sequence.
  4. Download the ZIP from EZGIF and unzip it.
  5. Use Select folder to open the unzipped folder.
  6. Play the animation, adjust the speed, and turn off unwanted frames.
  7. When the animation is ready, click Export sprite sheet.
  8. The export window automatically picks the top-right background color. If needed, enter a HEX code or use Pick from image to sample the correct color.
  9. Choose the centred square crop size. It defaults to the height of the first selected image; for example, enter 512 to crop every frame from its centre into a 512 × 512 pixel square.
  10. Set the background-color tolerance and export quality.
  11. Enter a filename and click Export PNG.

Use the exported PNG sprite sheet in your game however you need.
